# ジャポニスム 前と後

[English](README.en.md)

**▶ [3Dで見る](https://lanni007.github.io/japonisme-universe/?lang=ja) · [分類年表](https://lanni007.github.io/japonisme-universe/timeline-lanes.html?lang=ja) · [カード式年表](https://lanni007.github.io/japonisme-universe/timeline.html?lang=ja) · [旧版を見る](https://lanni007.github.io/japonisme-universe/previous/?lang=ja)**

地域の3D表示と2種類の年表を収録しています。更新前の公開版は `previous/` に保存しています。

**利用条件：閲覧・リンク共有はできます。今後の新規部分の無断再配布・商用利用等は認めません。以前のMIT／CC BY 4.0の許可と外部素材の条件は維持します。詳しくは [LICENSE](LICENSE) を参照してください。**

日本の美が海を渡り、世界の芸術や文化に影響を与え、日本へ帰ってくる流れをたどる、3Dの関連図です。前史と出島の貿易から、印象派、アール・ヌーヴォー、戦後の映画とアニメまでをつないでいます。

`index.html`（3D）または `timeline.html`（年表）をブラウザで開くと使えます。同じフォルダの `data/` と `images/` も必要です。58項目の図版を外部WebPとして保存し、年表は幅320pxのサムネイルを必要な位置で読み込みます。画像の出典と利用条件は各項目から確認できます。Three.jsは同梱しており、外部フォントが読めないときも標準フォントで表示します。

## 操作

- 右上の「日本語 / English」で、操作・項目説明・物語・鳥居の章名・画像タイトルを切り替えます。旅の位置や選択中の項目は保ちます。
- [英語表示へ直接開く](https://lanni007.github.io/japonisme-universe/?lang=en)こともできます。URLの `?lang=ja` / `?lang=en` が優先され、保存できるブラウザでは前回の言語を覚えます。指定や保存済み設定がない場合は日本語で表示します。
- 利用条件は [LICENSE](LICENSE) と [LICENSE-DATA.md](LICENSE-DATA.md) で確認できます。
- 「年表で読む」で縦スクロールの年表へ移ります。「3Dで見る」でその項目の3D表示へ戻れます。
- 地域の球体は年代に応じて名前・統合・分割が変わります。人物は登録された活動拠点に沿って配置します。
- 「物語で見る」で関連する出来事を順にたどれます。
- 「金のレールに乗る」で黄色いレールに沿って時間旅行をします。9つの赤い鳥居が章の変わり目を示します。
- 右上に現在の年代が大きく表示されます。出現した点とネットワークは、初期設定では残ります。図版は旅の途中で順番に約4秒表示します。「止めて詳しく読む」のあと、「○○年から旅を再開」で続きを見られます。
- 速度スライダーで0.25〜3.00倍、図版サイズのスライダーで60〜160%（拡大画面では25〜200%）に調整できます。画像は画面内に収まるように表示します。
- 画像や星を選ぶと、説明と関連項目、画像の制作者・ライセンス・原資料を確認できます。
- PCはドラッグで回転、ホイールで拡大・縮小。タッチ操作は1本指で回転、2本指で拡大・縮小。

## 制作途中です

情報とUIには、まだ修正・追加が必要な箇所があります。英訳は史実・通説・作者の読み解きの区別を引き継いでいますが、全ての歴史的記述を再検証したものではありません。誤りやよりよい出典はIssueでお知らせください。

## 収録内容

葛飾北斎、歌川広重、モネ、ドガ、ゴッホ、ミュシャ、各地の万博、刀・漆器・伊万里などの図版を収録しています。戦後の章には黒澤明、溝口健二、宮崎駿と『千と千尋の神隠し』のアカデミー賞も含みます。

人物の肖像、作品、品物の参考例、建築の現代の写真を図版名で区別しています。図版の制作・撮影年と、関連図の項目の年代はそれぞれの表示を参照してください。

線の種類は「影響」「人の縁」「時代の力」「証言」「共通の型」「仮説」「後世の見方」です。「共通の型」「仮説」は作者の読み解きを含みます。通説や解釈には説明文でその旨を示しています。誤りやよりよい出典はIssueでお知らせください。

## 年表で読む

本筋の9章に全217項目を配置し、年代のない「共通の型」は末尾にまとめます。章に明示された項目はその章に属し、複数の章に含まれる項目は最初の章に置きます。その他の項目は章の開始年を目安に配置するため、章の年代範囲は重なります。11の物語を切り替えて読むこともできます。つながりの種類・理由から関連カードへ移動し、「3Dで見る」でその星を開けます。別の物語にしかない項目へ移動すると、本筋へ切り替えて表示します。図版を押すと原資料・制作者・ライセンスと大きい画像を確認できます。

既存の説明文・英訳・関係線を引き継ぎ、下記の収録対象と章名を見直しています。年表と3Dは同じデータを読み込みます。ファイルを移す場合はこのフォルダ全体をコピーしてください。更新前の公開版は [previous/](previous/) から開けます。

## 分類で比べる年表（試作）

[timeline-lanes.html](timeline-lanes.html?lang=ja) は年代を縦、役割を横に並べる年表です。年代のある193項目を「外部環境・内圧・日本の美・仲介／万博・人物・様式／作品」に配置し、右端の「日本で起きた変化」に15件の解説を添えます。解説は既存の説明から整理し、起点の年より後の変化を含む場合は「以後の変化」と明記します。ビゴーとロティは「海外のまなざし」と表示し、作者の読み解きや後世の見方にあたる関係は破線で区別します。

年代のない「共通の型」24件は、上部のボタンと関連項目の補足から読めます。年代や地域で絞っても補足を参照できます。同じ年の記録は同じ段に置き、年の間隔は均等ではありません。項目を選ぶとつながりを強調し、「選択とつながりだけ」に絞れます。地域・年代・物語で絞り込めます。地域名は記録の年代、登録済みの人物はその年代の活動場所から表示します。スマホは年表の枠の中を上下左右にスクロールし、「列へ移動」で分類を選べます。元の本文・共有データは維持しています。カード式年表は timeline.html、更新前の公開版は previous/ に残しています。
